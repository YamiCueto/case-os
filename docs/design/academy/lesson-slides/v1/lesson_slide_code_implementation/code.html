The Softmax Concept

Unlike deterministic `if/else` logic, LLMs output a probability distribution over the vocabulary. The code block on the right demonstrates a simplified version of this.

  • check Logits are raw scores.
  • check Softmax converts them to probabilities summing to 1.
  • check Temperature controls randomness.
calculate_prob.py 
import numpy as np

def softmax(logits, temperature=1.0):
    """
    Compute softmax values for each sets of scores in logits.
    """
    # Apply temperature scaling
    scaled_logits = np.array(logits) / temperature
    
    # Subtract max for numerical stability
    exp_logits = np.exp(scaled_logits - np.max(scaled_logits))
    
    return exp_logits / exp_logits.sum(axis=0)

# Example usage:
# Vocabulary context: "The cat sat on the..."
vocab = ["mat", "dog", "moon"]
raw_logits = [8.5, 2.1, -1.0]

probabilities = softmax(raw_logits)

for word, prob in zip(vocab, probabilities):
    print(f"{word}: {prob:.4f}")
