CASE Academy Design Guidelines

Comprehensive design tokens and structural patterns for the CASE Engineering Hub. Adhere strictly to these values for consistent application rendering.

1. Color Palette

The system uses a Brutalist-Lite approach with high-contrast dark mode and selective digital blue accents.

Level 0 (Canvas)
HEX: #050505
Tailwind: bg-background
Level 1 (Surface)
HEX: #0A0A0A
Tailwind: bg-surface-container
Dividers
HEX: #1F1F1F
Tailwind: border-border-muted
Primary Accent
HEX: #007AFF
Tailwind: text-primary

2. Typography

Hierarchy defined by Inter for reading and JetBrains Mono for technical data.

Token Family Size / Weight Example
display Inter 32px / 600 Page Headline
headline-md Inter 20px / 500 Section Title
body-base Inter 14px / 400 Standard paragraph text used for descriptions.
label-mono JetBrains Mono 12px / 500 0xTECHNICAL_DATA
