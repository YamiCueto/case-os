# M02 — Prompt Engineering

Guías de tutor para enseñar Prompt Engineering como diseño de contratos de comportamiento, no como conversación ni búsqueda de palabras mágicas.

## Hilo conductor

```text
Modelo probabilístico
        ↓
Instrucción ambigua
        ↓
Restricciones, delimitadores y ejemplos
        ↓
Salida estructurada
        ↓
Validación determinista
```

Las guías están pensadas para sesiones en vivo de aproximadamente dos horas. Los tiempos de lectura que muestra CASE Academy son una referencia de autoestudio, no la duración de tu clase.
