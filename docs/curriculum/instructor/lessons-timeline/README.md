# Guías timeline para instructores

Este directorio reúne las guías para impartir CASE Academy en sesiones en vivo. Cada guía traduce la lectura de la aplicación a una clase que el tutor puede conducir desde pantalla, presencialmente o por Teams/Meet.

## Cómo usar estas guías

La duración indicada en la app representa principalmente lectura o estudio individual. Para la clase en vivo, usa **aproximadamente dos horas** como referencia flexible —por ejemplo, entre 17:00 y 19:00— para explicar, preguntar, demostrar y practicar.

La secuencia recomendada es:

```text
Pregunta que abre el problema
        ↓
Concepto técnico breve y fácil de explicar
        ↓
Ejemplo o demo en pantalla
        ↓
Ejercicio guiado en clase
        ↓
Puesta en común y cierre hacia la siguiente lección
```

No es necesario respetar cada minuto de forma rígida. Ajusta el ritmo según las preguntas y el nivel del grupo, procurando conservar práctica y cierre.

## Convenciones de cada guía

Las guías deben incluir, cuando aplique:

- Resultado de aprendizaje y pregunta guía.
- Conceptos explicados en lenguaje natural antes de usar términos técnicos.
- Timeline flexible de aproximadamente dos horas.
- Ejemplos que puedan mostrarse o escribirse en pantalla.
- Ejercicios simples, discusión y respuesta esperada para el tutor.
- Limitaciones de demos o simulaciones claramente declaradas.
- Cierre que conecte con la siguiente actividad o módulo.

## Principio de seguridad para ejercicios

En demos y laboratorios utiliza datos ficticios, públicos o aprobados. No compartas secretos, credenciales, datos personales ni código propietario con herramientas no autorizadas.

## Organización

Cada carpeta de módulo contiene su propio `README.md` y las guías de lecciones, demos y laboratorios disponibles. El contenido de estas guías debe mantenerse alineado con la experiencia y las rutas de CASE Academy.
