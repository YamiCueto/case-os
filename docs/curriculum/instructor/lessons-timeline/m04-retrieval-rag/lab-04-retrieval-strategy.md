# M04 · Laboratorio 04 — Diseñar una estrategia de recuperación

**Duración sugerida en vivo:** aproximadamente 2 horas.
**Entregable:** una estrategia de recuperación para un caso autorizado o ficticio.

## Misión

Los equipos definen cómo encontrarán candidatos útiles, no cómo redactará el modelo. Deben indicar fuente, consulta, filtros, Top-K, evaluación y criterio para ajustar la estrategia.

## Timeline

| Tiempo | Conducción |
| --- | --- |
| 17:00–17:15 | Presenta el caso y el límite de seguridad. |
| 17:15–17:35 | Definen la fuente y cinco consultas de prueba. |
| 17:35–18:00 | Deciden fragmentación, filtros y Top-K inicial. |
| 18:00–18:15 | Pausa y revisión cruzada. |
| 18:15–18:40 | Definen cómo medir precisión y cobertura. |
| 18:40–19:00 | Presentan riesgos, decisiones y siguiente ajuste. |

## Checklist docente

- [ ] La fuente está autorizada y no incluye secretos ni datos personales.
- [ ] Las consultas representan necesidades reales, no solo palabras clave.
- [ ] Top-K y filtros tienen justificación.
- [ ] Hay una forma explícita de revisar precisión y cobertura.
- [ ] El equipo distingue recuperar candidatos de construir el contexto final.

## Cierre

La recuperación encuentra evidencia; M05 utilizará esa capacidad como parte de flujos donde un agente decide qué acción o herramienta usar.
