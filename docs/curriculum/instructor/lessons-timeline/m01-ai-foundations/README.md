# M01 — Fundamentos de IA

Guías de tutor para introducir los LLMs como componentes probabilísticos dentro de sistemas de software.

## Ritmo de facilitación

Los tiempos visibles en CASE Academy describen la lectura individual de la plataforma. Estas guías están diseñadas para sesiones en vivo de aproximadamente **dos horas**, con horario de referencia **17:00–19:00**. Ese tiempo incluye explicación, participación, demostraciones, ejercicios, discusión y cierre; no es necesario tratar cada minuto como fijo.

## Hilo conductor del módulo

```text
Código determinista
        ↓
Predicción probabilística
        ↓
Tokens, contexto y costo
        ↓
Riesgo de alucinación
        ↓
Sistema determinista que controla al modelo
```
