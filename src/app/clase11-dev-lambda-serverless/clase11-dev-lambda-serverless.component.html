Resumen — Migración UI Legacy a Angular 22

compare_arrows

Legado → Moderno

  • VB6 Form → Standalone Component
  • Eventos VB6 (Click, Change) → Reactive Forms
  • Variables globales Form → signal()
  • Binding manual (txtNombre.Text) → Two-way data binding
  • MsgBox / MessageBox → signal error + @if en template
inventory

Stack Angular 22

  • signal() / computed() / effect() — sin Zone.js
  • @for / @if — nueva sintaxis de control flow
  • ReactiveFormsModule + Validators
  • inject() — sin constructor DI verboso
  • HttpClient tipado con interfaces Java-compatible
