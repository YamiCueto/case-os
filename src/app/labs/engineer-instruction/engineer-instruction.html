Engineer the Instruction

Iteración y validación de outputs estructurados

Problema del Ingeniero

Tu backend automatizado procesa código defectuoso y necesita que el LLM devuelva un JSON estricto para guardarlo en la base de datos. Si el modelo devuelve texto extra (como saludos o markdown), tu parser hará un crash.

Objetivo:

  1. Diseña una instrucción para analizar el código de abajo.
  2. Observa el Nivel 1 de Fallo: Unparseable (Texto basura rompe `JSON.parse`).
  3. Añade constraints ("ONLY JSON"). Observa el Nivel 2 de Fallo: Parseable but Invalid (Es JSON válido, pero inventa propiedades).
  4. Itera: Añade un Schema exacto (vulnerability, severity, fix) para superar la validación.
