◈ Concepto para llevar

Los LLMs no procesan palabras — procesan tokens. Un token puede ser una palabra completa, una sílaba, un signo de puntuación o un espacio. La ventana de contexto mide cuántos tokens puede "ver" el modelo a la vez, y cada token tiene un costo de inferencia. Optimizar tokens es optimizar costo y calidad.
