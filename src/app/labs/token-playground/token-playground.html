Objetivo del Laboratorio

Construir y probar una herramienta para estimar la cantidad de tokens de un texto.

Experimenta:

  1. Escribe un prompt cualquiera.
  2. Observa la cantidad de tokens y el costo estimado.
  3. Ahora modifica el prompt, cambia una palabra por un sinónimo o añade signos de exclamación.
  4. ¿Qué cambió en los tokens visualizados? ¿Por qué se rompen las palabras? ¿Qué relación tiene con el límite de contexto?
