MCP Core Concepts

Reference Cheat Sheet (Spec 2026-07-28)

Model Context Protocol (MCP) es un estándar abierto de interoperabilidad para conectar asistentes de IA (Clientes) con fuentes de datos (Servidores). A continuación, las definiciones clave.

1. Topología de Red

Host

La aplicación principal (ej. Claude Desktop, Cursor). Un Host puede iniciar múltiples Clientes MCP para conectarse a diferentes servidores simultáneamente. Maneja la UI y las interacciones con el modelo (LLM).

Client

Mantiene la conexión (protocolo 1 a 1) con un Servidor MCP específico. Transfiere peticiones desde el Host hacia el Servidor y maneja las respuestas.

Server

Un proceso ligero y stateless que expone el acceso a sistemas externos (BDs, APIs locales). Al conectarse, declara sus capacidades (Capability Discovery).

2. Transportes (Conectividad)

STDIO

El estándar para integraciones locales. El Host levanta el proceso del Servidor como un subproceso y se comunican enviando JSON-RPC bidireccional por Standard Input y Standard Output.

Streamable HTTP

El estándar para integraciones remotas (Nube, Corporativas). Supera las limitaciones del antiguo HTTP+SSE, permitiendo flujos persistentes compatibles con proxies y firewalls modernos.

3. Primitivas (Capacidades)

Resources (Datos / Contexto)

Representan datos Read-Only controlados por el Servidor. Se identifican mediante URIs (ej. file:///..., postgres://...). El agente o el usuario "leen" este contexto.

Tools (Acciones / Mutaciones)

Operaciones ejecutables (Read/Write) controladas activamente por el Modelo de IA (LLM). Requieren que el Host solicite aprobación (Human in the Loop) ya que pueden alterar el estado de sistemas externos.

Prompts (Templates)

Plantillas de texto parametrizadas definidas por el Servidor para interactuar de forma estándar con el dominio (ej. un prompt estructurado para hacer code-review de un Pull Request específico).

Capability Discovery: MCP es un protocolo sin estado. Al iniciar la conexión, el Cliente realiza un Handshake y el Servidor envía la lista completa de Resources, Tools y Prompts que tiene disponibles. Esto elimina la necesidad de pre-configurar manualmente cada integración.
