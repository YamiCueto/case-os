Context Engineering Checklist

Validación arquitectónica antes de inferencia

📋

Checklist de Pre-Ensamblado

  • 1. Relevancia (Relevance) ¿La información incluida es estrictamente necesaria para responder al intent actual? ¿Se filtró el ruido (ej. menús, footers de HTML, datos no relacionados)?
  • 2. Recencia (Recency) En datos secuenciales (conversaciones, logs), ¿estamos priorizando lo más reciente y truncando o resumiendo lo antiguo?
  • 3. Redundancia (Redundancy) ¿Estamos repitiendo los mismos system prompts o el estado estático en cada petición de un hilo de conversación? (Considerar caché de contexto).
  • 4. Presupuesto (Budget) ¿El payload final respeta el límite duro de tokens? ¿Hay margen para que el modelo devuelva la respuesta (Output Tokens)?
