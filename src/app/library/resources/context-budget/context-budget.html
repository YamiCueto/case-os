Context Budget Utility

Snippet para truncado y estimación de tokens en tiempo de ejecución

context-budget.utils.ts

Role: UTILITY 
/**
 * Utility para gestionar el presupuesto de tokens (Estimación rápida de 4 chars por token)
 * Útil para truncar historiales o payloads antes de enviarlos al LLM.
 */

export class ContextBudgetManager {{ '{' }}
  private readonly MAX_TOKENS: number;
  private readonly SYSTEM_RESERVE: number; // Tokens reservados para System Prompt y Schema

  constructor(maxTokens: number = 8000, systemReserve: number = 1500) {{ '{' }}
    this.MAX_TOKENS = maxTokens;
    this.SYSTEM_RESERVE = systemReserve;
  {{ '}' }}

  // Estimación aproximada (Rápida, no exacta como TikToken)
  public estimateTokens(text: string): number {{ '{' }}
    return Math.ceil(text.length / 4);
  {{ '}' }}

  public getAvailableBudget(): number {{ '{' }}
    return this.MAX_TOKENS - this.SYSTEM_RESERVE;
  {{ '}' }}

  /**
   * Recibe un array de mensajes históricos y devuelve solo los más recientes
   * que caben en el presupuesto proporcionado.
   */
  public compressHistory(messages: {{ '{' }}role: string, content: string{{ '}' }}[], budget: number = 2000): any[] {{ '{' }}
    let currentUsage = 0;
    const compressed = [];

    // Iteramos de atrás hacia adelante (más reciente primero)
    for (let i = messages.length - 1; i >= 0; i--) {{ '{' }}
      const msgTokens = this.estimateTokens(messages[i].content);
      
      if (currentUsage + msgTokens <= budget) {{ '{' }}
        compressed.unshift(messages[i]);
        currentUsage += msgTokens;
      {{ '}' }} else {{ '{' }}
        // Se acabó el presupuesto
        break;
      {{ '}' }}
    {{ '}' }}
    return compressed;
  {{ '}' }}
{{ '}' }}

Estrategia Defensiva

Este snippet es una defensa de Nivel 1. Estima a la baja dividiendo por 4 (promedio en inglés) e iterando el historial de abajo hacia arriba (Recency). Así asegura que el Contexto nunca rompa el límite duro de la API del LLM, descartando primero la información más antigua (Truncation controlado).
