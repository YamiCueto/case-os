Agentic Code Review Checklist

Guía de verificación para código generado por agentes

Cuando trabajas con agentes autónomos o AI Coding Assistants, el código se genera rápido, pero la responsabilidad de que funcione de manera segura y eficiente recae en ti (Human in the Loop). Utiliza este checklist antes de aprobar cualquier Pull Request (PR) o Patch generado por IA.

Pre-Generación

1. Context Completeness & Specification

  • ¿Se le proveyó al agente el contexto adecuado (archivos, dependencias, tipos) sin exceso de ruido?
  • ¿El requerimiento de negocio o la descripción del bug estaban claros y libres de ambigüedad?
Ejecución

2. Tests & Verification

  • ¿El código incluye pruebas automatizadas (Unit/Integration tests) para validar el comportamiento esperado?
  • ¿Se ejecutó la suite de tests existente y todo pasó exitosamente?
Impacto

3. Regression Risk & Architecture

  • ¿El agente reinventó la rueda en lugar de utilizar servicios/utilidades ya existentes en el codebase?
  • ¿Existen refactorizaciones innecesarias (ej. cambio de sintaxis o librerías) en áreas no relacionadas al requerimiento original?
Protección

4. Security Considerations

  • ¿El agente alucinó dependencias inexistentes (vulnerabilidad de Dependency Confusion)?
  • ¿Se están sanitizando los inputs y protegiendo datos sensibles antes de interactuar con APIs de terceros o bases de datos?
Conclusión de Aprobación Humana: Solo aprueba el código generado si puedes afirmar que tú mismo lo habrías escrito o diseñado de esa manera tras una revisión exhaustiva.
