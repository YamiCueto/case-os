Prompt Design Checklist

Guía de validación para paso a producción

📋

Checklist de Ingeniería

  • 1. Contexto Delimitado ¿Están los datos del usuario claramente separados de las instrucciones usando delimitadores como XML tags (ej. <user_input>)?
  • 2. Zero-Shot vs Few-Shot Si el formato es estricto, ¿has incluido al menos 2 ejemplos representativos (Input/Output) dentro del prompt?
  • 3. Negative Constraints ¿Hay instrucciones claras sobre lo que el modelo NO debe hacer? (ej. "NO incluyas markdown", "NO inventes datos").
  • 4. Fallback Behavior ¿Sabe el modelo cómo responder si no puede completar la tarea? (ej. devolver un JSON vacío o un error tipado).
  • 5. Chain of Thought Si la tarea requiere análisis, ¿le pediste que evalúe y "piense paso a paso" antes de generar el output final?
