Semana 1

🎯 Lo que aprenderás:

  • Fundamentos e instalación del Model Context Protocol (MCP)
  • Flujos de trabajo con agentes autónomos en IDEs (Cursor / Windsurf / Copilot)

Semana 2 / Clase 2: Microservicio Spring Boot 3.4+ con Java 21

Semana 2

Reto: Generación completa de microservicio de Gestión Crediticia con Java 21 Virtual Threads.

📦 Stack:

Java 21, Spring Boot 3.4+, Virtual Threads, Spring Data JPA, MapStruct, OpenAPI 3

🎯 Lo que aprenderás:

  • Arquitectura Hexagonal con asistencia de razonamiento de IA
  • Modelado de entidades JPA y optimización de consultas con Virtual Threads
  • Controladores REST documentados con OpenAPI / Swagger
  • Validaciones robustas con Bean Validation y DTOs inmutables (Java Records)

Semana 3 / Clase 3: Migración Legacy VB6 / Java 8 a Spring Boot 3.4

Semana 3

Reto: Analizar módulo VB6/Java 8 legacy y convertirlo automáticamente a Spring Boot 3.4.

🔄 Casos de Migración:

  • Lógica imperativa en VB6/Procedimientos Almacenados → Servicios Java 21 limpios
  • Consultas SQL nativas empotradas → Spring Data JPA & Criteria API
  • Validaciones de UI legacy → Capas de dominio decoupled

Semana 4 / Clase 4: APIs REST, Resilience4j & Creación de Servidor MCP

Semana 4

Reto: Integrar resiliencia en APIs externas y exponerlas como herramientas MCP para Agentes de IA.

📦 Stack:

Spring WebClient, Resilience4j (Circuit Breaker, Retry), Redis, MCP SDK

🎯 Lo que aprenderás:

  • Patrones de resiliencia con Resilience4j y Spring WebClient
  • Transformación de endpoints OpenAPI a herramientas de Servidor MCP
  • Conexión de agentes de IA a la base de datos empresarial mediante MCP Tools
