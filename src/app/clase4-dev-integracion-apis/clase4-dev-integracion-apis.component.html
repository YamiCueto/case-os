warning
Importante:

La integración con APIs externas heredadas (COBIS, bureaus) es crítica. Un fallo puede detener operaciones crediticias. Siempre implementa @CircuitBreaker, timeout configurado en build.gradle, fallback con respuesta degradada y monitoreo con Actuator.

Resumen

inventory

Stack Tecnológico

  • Java 21 LTS + Virtual Threads
  • Spring Boot 4.1.0 + Gradle 8
  • @HttpExchange (cliente declarativo)
  • @Retryable + @CircuitBreaker
  • WireMock (Testing de integraciones)
compare_arrows

Legado → Moderno

  • XMLHTTP VB6 → @HttpExchange interface
  • ServiceReference .NET → proxy Spring
  • COBIS SOAP/XML → REST/JSON declarativo
  • Type/Struct VB6 → Java Record inmutable
  • On Error GoTo → @Retryable + @CircuitBreaker
