¿Qué es un Token?

Un modelo de lenguaje no lee palabras completas, lee tokens. Un token es un fragmento de texto (una sílaba, una palabra corta o un símbolo).

  • En inglés, 1 token ≈ ¾ de una palabra (100 tokens ≈ 75 palabras).
  • En español o código fuente, cada palabra se rompe en múltiples tokens, aumentando el costo.
  • El modelo convierte estos tokens en IDs para poder procesarlos matemáticamente.

Ejemplo de Tokenización

La frase "Ingeniería de software" podría dividirse así:

["Ingen", "ier", "ía", " de", " software"]

Por eso los LLMs son malos resolviendo anagramas: ¡no ven las letras, ven fragmentos estadísticos!

Context Window Limit

Todo modelo tiene un límite máximo de tokens que puede "ver" a la vez. Este límite incluye el prompt de entrada + la respuesta generada.

  • GPT-3: 4K tokens.
  • Claude 3 / GPT-4o: 128K - 200K tokens.
  • Gemini 1.5 Pro: Hasta 2 Millones de tokens.
Restricción de Ingeniería: Meter 128K tokens de contexto en cada petición cuesta dinero y tiempo. "Context Engineering" se trata de mandar solo lo estrictamente necesario para resolver la tarea.

Temperatura y Sampling

Controlando el "Caos" Matemático

Al predecir el siguiente token, el LLM calcula una distribución de probabilidad para todos los tokens posibles. La Temperatura manipula esas probabilidades en tiempo de ejecución.

Temp: 0.0

Extracción y Código

El modelo casi siempre elegirá el token más probable. Las respuestas son deterministas, repetitivas y precisas.

Ideal para: RAG, código, JSON
Temp: 0.8+

Creatividad

Se achatan las probabilidades, permitiendo que tokens menos probables sean elegidos. Respuestas variadas.

Ideal para: Lluvia de ideas, redacción

Tokens de Entrada vs Salida

En el uso de APIs comerciales, el costo se divide en dos factores principales de computación:

  • Input Tokens (Prompt): Procesamiento en paralelo, más rápidos y baratos.
  • Output Tokens (Generación): Procesamiento secuencial (auto-regresivo). Suelen costar entre 3x y 5x más.
