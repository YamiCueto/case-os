Anatomía de la Inferencia

Tokens, Ventana de Contexto y Temperatura

¿Qué es un Token?

Un modelo de lenguaje no lee palabras completas, lee tokens. Un token es un fragmento de texto (una sílaba, una palabra corta o un símbolo).

  • En inglés, 1 token ≈ ¾ de una palabra (100 tokens ≈ 75 palabras).
  • En español o código fuente, a veces cada palabra se rompe en múltiples tokens, aumentando el costo.
  • El modelo convierte estos tokens en números (IDs) para poder procesarlos matemáticamente.

Ejemplo de Tokenización

La frase "Ingeniería de software" podría dividirse así:

["Ingen", "ier", "ía", " de", " software"]

Por eso los LLMs son malos para contar letras o resolver anagramas: ¡ellos no ven las letras, ven fragmentos!

Context Window Limit

Todo modelo tiene un límite máximo de tokens que puede "ver" a la vez. Este límite incluye el prompt de entrada + la respuesta generada.

  • GPT-3 tenía 4K tokens.
  • Claude 3 / GPT-4o tienen 128K - 200K tokens.
  • Gemini 1.5 Pro tiene hasta 2 Millones de tokens.
El problema de la latencia y el costo: Meter 128K tokens de contexto en cada petición cuesta dinero y tiempo. "Context Engineering" se trata de mandar solo lo estrictamente necesario para resolver la tarea.

Temperatura y Sampling

Controlando el "Caos" Matemático

Al predecir el siguiente token, el LLM calcula una distribución de probabilidad para todos los tokens posibles. La Temperatura manipula esas probabilidades.

Temperatura 0.0

Extracción y Código

El modelo casi siempre elegirá el token más probable. Las respuestas son deterministas y repetitivas.

Ideal para: RAG, código, JSON, extracción de datos.

Temperatura 0.8+

Creatividad

Se achatan las probabilidades, permitiendo que tokens menos probables sean elegidos. Las respuestas son variadas y creativas.

Ideal para: Lluvia de ideas, redacción, marketing.

Tokens de Entrada vs Salida

En el uso de APIs comerciales (OpenAI, Anthropic, Bedrock), el costo se divide en dos:

  • Input Tokens (Prompt): Generalmente son más baratos de procesar.
  • Output Tokens (Generación): Suelen costar entre el triple y cinco veces más, ya que generar toma más ciclos de cómputo.

Diseñar prompts que devuelvan respuestas concisas (JSON estricto) no solo ahorra tiempo, sino mucho dinero en producción.
