LAB 09 · REAL ENGINEERING Module 09 · Architecture · ⏱️ 90 min · Expert · System Migration

Diseña el Plano de Arquitectura de Modernización con IA. No construyas desde cero; elige un sistema Legacy existente en tu organización y define la arquitectura requerida para modernizarlo usando IA, justificando estrictamente la inclusión o exclusión de cada componente.

00 —

Legacy System & Business Requirement

¿Qué sistema vamos a modernizar y por qué?

  • Arquitectura actual (ej. Monolito en Java, Base de datos en MySQL).
  • El proceso de negocio que deseamos automatizar o mejorar.
  • El objetivo de negocio medible (ej. "Reducir tiempo de respuesta en soporte un 40%").
01 —

Constraints

Las limitaciones que tu arquitectura no puede romper bajo ninguna circunstancia.

  • Límites operativos: Latencia máxima, presupuesto por llamada.
  • Privacidad de datos: GDPR, Compliance, información sensible que no debe salir.
02 —

Capability Decision Matrix

Mapea tus requerimientos a las capacidades GenAI correspondientes. Ningún componente entra gratis.

Capability Required? Why? Decision
LLM Engine Yes Generate text classification INCLUDE
RAG Pipeline Yes Internal knowledge access needed INCLUDE
Agent Loop No Workflow is strictly deterministic EXCLUDE
MCP Client No No external actions are performed EXCLUDE
Eval Pipeline Yes Regression control prior to deployment INCLUDE
03 —

Security & Evaluation Boundaries

Integra los contratos definidos en M07 y M08. Define cómo evaluarás el sistema antes del despliegue y cómo protegerás el sistema contra inyecciones y exfiltración.

04 —

Target Architecture

Dibuja o documenta tu arquitectura final propuesta incorporando los componentes seleccionados de tu matriz.

05 —

Migration Boundary

¿Qué cambia ahora y qué permanece legacy?

  • Qué componente legacy permanece intacto.
  • Qué componente se reemplaza por el motor AI.
  • Qué componente se "envuelve" (wraps) con una API.
  • Por dónde entra y sale el flujo de información de la IA.
  • Estrategia de Rollback (si la IA falla en producción).
