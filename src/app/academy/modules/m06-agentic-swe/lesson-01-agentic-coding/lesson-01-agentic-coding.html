From Completion to Agents

La evolución de la asistencia generativa

No es "Magia" Programadora

Los modelos no se convirtieron súbitamente en "mejores programadores" por arte de magia. La transición hacia el Agentic Coding ocurre porque aprendimos a rodear a estos modelos probabilísticos con infraestructuras deterministas robustas.

Concepto Clave: El código no es más que lógica altamente estructurada. Los LLMs son excelentes en esto, pero su verdadero poder destructivo surge cuando los conectamos a contexto, herramientas y ciclos de feedback.
● Módulo 06: Agentic SWE

El Salto Evolutivo

Cómo llegamos aquí

Code Completion
El modelo predice las siguientes 10 líneas basado en el archivo actual. (Ej. Copilot inicial).
↓
Code Generation
El modelo genera un componente completo a partir de un prompt. (Ej. ChatGPT).
↓
Codebase Context
El prompt se inyecta con RAG sobre todo el repositorio. Genera código respetando convenciones.
↓
Agentic Coding
El modelo busca contexto activamente (Tool Use), propone código, ejecuta tests, lee errores y se corrige a sí mismo en un Agent Loop.
● Módulo 06: Agentic SWE

Es la suma de sus partes

Agentic SWE = M03 + M04 + M05

Un Asistente Agentic (como Cursor o Devin) no es un "modelo especial". Es la orquestación perfecta de las piezas que ya aprendiste:

🧠

Context (M03)

El sistema decide qué archivos, librerías y dependencias incluir en el prompt.

🔍

Retrieval (M04)

El sistema busca fragmentos de código similares mediante embeddings para guiar la sintaxis.

🔄

Agent Loop (M05)

El sistema propone un parche (Action), corre el test (Tool), lee el stacktrace (Observation) e itera.

● Módulo 06: Agentic SWE

El Rol del Humano

Si el agente programa, ¿qué hacemos nosotros?

👤

El desplazamiento del trabajo

Al igual que los compiladores nos liberaron de escribir código máquina, el Agentic Coding nos está liberando de la sintaxis repetitiva.

Pero el modelo sigue siendo probabilístico. No "entiende" los objetivos de negocio ni la arquitectura global. Requiere especificación estricta y, sobre todo, verificación rigurosa.
