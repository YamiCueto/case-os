VALIDACIÓN FALLIDA

¿Qué aprendiste?

La instrucción permitió que el modelo respondiera en lenguaje natural. Aunque la respuesta contiene información correcta, no cumple el formato que nuestro software necesita.

El sistema esperaba únicamente un objeto JSON, pero recibió texto. Por eso JSON.parse() no pudo procesar la respuesta y la automatización colapsó.

¿Qué aprendiste?

El modelo devolvió un JSON, pero también agregó bloques Markdown (```json) y texto adicional introductorio.

Además, el esquema que inventó el modelo (error_encontrado, sugerencia) no coincide con lo que espera el código de tu aplicación (status, severity, issue). Pedir "JSON" no es suficiente para definir un contrato.
