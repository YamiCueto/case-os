JSON & Schemas

Forzando el formato

La técnica más efectiva para obtener datos estructurados es proveer un Schema Tipado (ej. TypeScript interface o JSON Schema) directamente en el prompt, y usar Few-Shot para demostrarlo.

📝

El Prompt Estructurado Perfecto:

Analiza el ticket de soporte y devuelve un JSON válido que cumpla estrictamente con este schema de TypeScript: interface TicketAnalysis {{ '{' }} severity: "LOW" | "MEDIUM" | "HIGH" | "CRITICAL"; is_bug: boolean; affected_component: string | null; summary: string; {{ '}' }} WARNING: Return ONLY valid JSON. No markdown backticks.

Manejo de Errores de Formato

Los modelos desobedecen. Prepárate.

🚨

Problemas Comunes

  • El modelo envuelve el JSON en ```json ... ```
  • Añade texto antes o después: "Aquí tienes el JSON solicitado:"
  • Falta escapar comillas internas.
  • Inventa nuevas propiedades que no estaban en tu Schema.
🛡️

Defensas de Software

  • Pre-procesamiento: Usa un regex para buscar la primera {{ '{' }} y la última {{ '}' }} antes de hacer JSON.parse().
  • Validación estricta: Usa librerías como Zod o Pydantic para validar la estructura parseada. Si falla, rechaza la respuesta.
