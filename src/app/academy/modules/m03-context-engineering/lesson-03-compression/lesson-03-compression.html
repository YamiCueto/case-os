El Presupuesto de Tokens

Todo modelo tiene una ventana máxima de tokens (ej. 128k) y un costo por token de entrada. Tratar de enviarlo todo no solo es caro, también vuelve lento al sistema. La compresión técnica busca maximizar la densidad de información.

Técnicas de Compresión

Truncar es para amateurs

✂️

Truncation (Evitar)

Cortar un string a los primeros 4000 caracteres. Rompe el formato (ej. corta JSON por la mitad), destruye XML tags y pierde la información más reciente.

🗜️

Distillation (Ideal)

Usar código para limpiar el contexto: eliminar campos null de un JSON, remover clases CSS de un HTML, resumir el historial de conversación con un modelo barato antes de llamar al modelo pesado.

● Módulo 03: Context Engineering

La Promesa Vacía

La realidad de la inferencia

Concepto de Ingeniería: Un contexto perfectamente seleccionado, ensamblado, priorizado y comprimido NO garantiza una respuesta correcta.

Simplemente hace que el sistema probabilístico tenga las mejores condiciones matemáticas posibles para producirla. La validación del Context Payload te asegura que no fallaste por falta de información. Si el LLM falla con un contexto perfecto, el problema está en las capacidades del modelo (Model) o en sus reglas (Instruction).
