Evaluación del Context Engine

PASS — Minimum Useful Context

Seleccionaste exactamente la información necesaria sin ruido histórico ni desborde de tokens. El modelo responderá con precisión máxima.

BUILDING CONTEXT PAYLOAD...

Selecciona las fuentes. Recuerda: incluye solo lo indispensable para resolver el intent y descarta el ruido promocional o histórico redundante.

FAIL — Noise / Overflow

Desombra fuentes no esenciales (ej. historial entero de 50 msgs o promociones) para volver dentro del presupuesto.

◈ Concepto para llevar

El principio en ingeniería de contexto no es simplemente "menos contexto", sino Minimum Useful Context: proveer todo lo estrictamente necesario sin introducir ruido que diluya la atención del modelo.
