Contrato de Autonomía: Intención vs Autoridad

El modelo probabilístico es un generador de propuestas, no una entidad con privilegios de ejecución. Toda llamada propuesta atraviesa un Policy Gate determinista antes de acceder al entorno.

check_circle READ → ALLOW

Herramientas de consulta de métricas e historial. Seguras para ejecución automática.

  • get_service_status(service)
  • search_incidents(service)
  • get_runbook(service)
flag WRITE → REQUIRE_APPROVAL

Acciones con efectos secundarios que alteran el sistema o generan compromisos.

  • create_ticket(service, severity, desc)
Requiere revalidación post-aprobación obligatoria.
block PRIVILEGED → BLOCK

Acciones críticas de infraestructura. Ningún prompt del usuario puede otorgar esta autoridad.

  • restart_service(service)
Bloqueo absoluto e inmutable en Policy Gate.
