◈ Takeaway

Un agente combina un modelo con un runtime que mantiene estado y controla el ciclo de ejecución. En cada iteración, el modelo utiliza el objetivo y las observaciones acumuladas para proponer la siguiente acción o finalizar. El runtime controla la ejecución, registra la observación y actualiza el estado.

Por eso diseñar agentes implica controlar herramientas, efectos externos y condiciones de parada; no solamente escribir un prompt.
