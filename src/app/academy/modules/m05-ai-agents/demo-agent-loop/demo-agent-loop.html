◈ Takeaway

Un Agente no es un modelo mágico. Es un bucle determinista de evaluación de estado. El LLM se invoca repetidamente, recibe las observaciones previas y genera la siguiente acción (Tool Call) o decide terminar. El principal riesgo son los bucles infinitos y las alucinaciones de argumentos.
