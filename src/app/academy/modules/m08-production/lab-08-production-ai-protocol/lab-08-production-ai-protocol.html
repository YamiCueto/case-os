LAB 08 · REAL ENGINEERING Module 08 · Production AI · ⏱️ 90 min · Advanced · Production Readiness Review

Diseña el Production Readiness Review de tu sistema. Este artefacto es la revisión de ingeniería final que determina si un agente de IA está autorizado a desplegarse, asegurando que cumple con las fronteras de seguridad, límites operativos y criterios de regresión definidos.

00 —

Production Baseline

Antes de modificar y evaluar, establece el punto de partida (Baseline Before AI). Documenta:

  • Versión actual del modelo y prompt.
  • Comportamiento y casos de error conocidos.
  • Latencia y costo actuales.
  • Restricciones operativas existentes.
01 —

Golden Dataset Definition

Define los casos de prueba inmutables que deben ejecutarse en cada despliegue.

  • Happy Paths: Uso estándar esperado.
  • Edge Cases: Casos ambiguos o límites.
  • Adversarial Inputs (Jailbreaks): Intentos de extraer datos o saltar reglas.
  • Regressions: Bugs resueltos en versiones anteriores que no deben reaparecer.
02 —

Evaluation Strategy

Diseña el pipeline de evaluación jerárquico. No uses LLMs para tareas determinísticas.

  • 1. Deterministic Checks: Validación de JSON Schema, Regex para PII, HTTP Status.
  • 2. Semantic Evaluation: Similitud de incrustaciones (embeddings) con respuestas esperadas.
  • 3. LLM-as-a-judge: Rúbrica para evaluar calidad, tono y completitud de la respuesta.
  • 4. Human Review: Validación final de métricas de aceptación de negocio.
03 —

Systemic Security Boundaries

Asume que el modelo será engañado (Prompt Injection). ¿Qué impide el desastre?

  • ¿Qué mecanismos de red o RBAC impiden la exfiltración de PII?
  • ¿Qué impide ejecutar operaciones destructivas si el LLM las solicita? (Referencia a Least Privilege en M07).
04 —

Operational Constraints

Aplica el principio de Least Complexity Necessary. Una respuesta perfecta que tarde 45 segundos o cueste el triple puede ser un Deployment Failure.

  • MAX LATENCY
  • MAX COST / REQUEST
  • MAX TOKENS
  • MAX RETRIES / TOOL CALLS
05 —

The Deployment Gate

No todas las métricas tienen el mismo peso. Define los Hard Blockers que impiden automáticamente el despliegue.

Evento Decisión Automática
SECURITY CRITICAL FAILURE BLOCK
PII EXFILTRATION BLOCK
UNAUTHORIZED SIDE EFFECT BLOCK
GOLDEN DATASET REGRESSION REVIEW
LATENCY / COST REGRESSION REVIEW
06 —

Final Decision

¿Estamos autorizados a desplegar este sistema?
