💡 Recomendaciones de Instalación

✅

Editor Principal: Visual Studio Code

Descarga desde code.visualstudio.com - Instala extensiones: GitHub Copilot, Python, Java, Angular

🤖

GitHub Copilot (Recomendado)

Suscripción desde github.com/copilot - $10/mes o gratis para estudiantes/profesores

🐍

Python 3.10+ para Clases 3, 4, 5

Descarga desde python.org - Incluye pip para instalar librerías (FastAPI, Selenium, pytest, Faker)

☕

Java 17+ (OpenJDK) para Clase 6

Descarga OpenJDK desde adoptium.net - Necesario para Spring Boot y Gradle

🅰️

Node.js 18+ y npm para Angular (Clases 7, 8, 9)

Descarga desde nodejs.org - Incluye npm. Luego instala Angular CLI: npm install -g @angular/cli

🔀

Git para Control de Versiones

Descarga desde git-scm.com - Crea cuenta en GitHub para colaboración

📌 Nota: No necesitas instalar todo desde el día 1. Cada clase indicará las herramientas específicas requeridas. El instructor compartirá guías de instalación paso a paso antes de cada taller práctico.
